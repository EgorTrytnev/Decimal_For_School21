# Makefile Usage Guide

## Основные команды

### Сборка и тестирование
```bash
# Сборка библиотеки и запуск базовых тестов
make all

# Только сборка библиотеки
make s21_decimal.a

# Запуск базовых тестов
make test

# Запуск тестов с Check библиотекой
make test_check
```

### Автоматическая очистка после тестирования
```bash
# Тестирование с автоматической очисткой
make test_clean      # Базовые тесты + очистка
make check_clean     # Check тесты + очистка
```

### Покрытие кода (gcov)
```bash
# Генерация отчета о покрытии кода
make gcov_report

# Отчет будет создан в coverage/html/index.html
```

### Установка библиотеки
```bash
# Установка в систему
make install

# Установка с автоматической очисткой
make install_clean
```

### Очистка
```bash
# Очистка временных файлов
make clean

# Полная очистка (включая gcov файлы)
make clean_all
```

## Соответствие требованиям README

✅ **C11 стандарт** - используется `-std=c11`  
✅ **GCC компилятор** - используется `gcc`  
✅ **POSIX.1-2017** - соблюдается  
✅ **Google Style** - код соответствует стилю  
✅ **Статическая библиотека** - создается `s21_decimal.a`  
✅ **Префикс s21_** - все функции имеют префикс  
✅ **Check библиотека** - используется для тестов  
✅ **Makefile targets** - все требуемые цели реализованы  
✅ **gcov отчет** - поддерживается HTML отчет  
✅ **Запрет __int128** - не используется  
✅ **Бинарное представление** - соответствует спецификации  

## Структура файлов после сборки

```
src/
├── s21_decimal.h              # Заголовочный файл
├── s21_helpers.c              # Исходные файлы
├── s21_is_less.c
├── s21_is_greater.c
├── s21_is_less_or_equal.c
├── s21_is_greater_or_equal.c
├── s21_from_int_to_decimal.c
└── s21_from_decimal_to_int.c

tests/
└── test_comparison.c          # Unit-тесты

s21_decimal.a                  # Статическая библиотека (после сборки)
coverage/                      # Отчеты покрытия (после gcov_report)
└── html/
    └── index.html
```

## Рекомендуемый workflow

1. **Разработка**: `make test_clean` - для быстрого тестирования
2. **Финальная проверка**: `make check_clean` - для полного тестирования
3. **Проверка покрытия**: `make gcov_report` - для анализа покрытия кода
4. **Установка**: `make install_clean` - для установки в систему

## Автоматическая очистка

Все команды с суффиксом `_clean` автоматически:
- Удаляют объектные файлы (.o)
- Удаляют временные файлы
- Удаляют gcov файлы (.gcno, .gcda, .gcov)
- Удаляют папку coverage
- Удаляют исполняемые файлы тестов

Это обеспечивает чистоту рабочего пространства после каждого запуска.
