# Level 4 Functions Implementation

## Обзор

Этот документ описывает реализацию функций **Уровня 4** для проекта s21_decimal. Данные функции отвечают за сравнение decimal чисел и конвертацию между int и decimal типами.

## Реализованные функции

### Функции сравнения

1. **s21_is_less** - Сравнение "меньше" (<)
2. **s21_is_greater** - Сравнение "больше" (>)
3. **s21_is_less_or_equal** - Сравнение "меньше или равно" (<=)
4. **s21_is_greater_or_equal** - Сравнение "больше или равно" (>=)

### Функции конвертации

1. **s21_from_int_to_decimal** - Преобразование из int в decimal
2. **s21_from_decimal_to_int** - Преобразование из decimal в int

## Архитектура

### Структура decimal

```c
typedef struct {
    int bits[4];
} s21_decimal;
```

- `bits[0]`, `bits[1]`, `bits[2]` - 96-битное целое число (младшие, средние, старшие 32 бита)
- `bits[3]` - знак и масштаб:
  - Бит 31: знак (0 = положительный, 1 = отрицательный)
  - Биты 16-23: масштаб (степень 10 от 0 до 28)

### Вспомогательные функции

- `s21_get_bit()` - получение бита по позиции
- `s21_set_bit()` - установка бита по позиции
- `s21_get_scale()` - получение масштаба
- `s21_set_scale()` - установка масштаба
- `s21_is_zero()` - проверка на ноль
- `s21_compare_magnitude()` - сравнение абсолютных значений

## Логика сравнения

### Алгоритм сравнения

1. **Проверка на ноль**: Если оба числа равны нулю, они считаются равными
2. **Сравнение знаков**: 
   - Если знаки разные, отрицательное число меньше положительного
   - Если знаки одинаковые, сравниваются абсолютные значения
3. **Сравнение абсолютных значений**: Поразрядное сравнение от старших к младшим битам

### Особенности реализации

- **Отрицательные числа**: При одинаковых знаках меньшее абсолютное значение больше для отрицательных чисел
- **Нули**: Положительный и отрицательный ноль считаются равными
- **Оптимизация**: `s21_is_less_or_equal` и `s21_is_greater_or_equal` используют инверсию соответствующих функций

## Логика конвертации

### int → decimal

1. Инициализация всех битов нулями
2. Установка знака для отрицательных чисел
3. Сохранение абсолютного значения в `bits[0]`

### decimal → int

1. Проверка, что значение помещается в 32 бита (только `bits[0]` используется)
2. Извлечение значения из `bits[0]`
3. Применение знака для отрицательных чисел
