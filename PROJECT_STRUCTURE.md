# s21_decimal Project Structure

## Обзор

Проект реализует библиотеку s21_decimal для работы с десятичными числами высокой точности. Вся разработка ведется внутри директории `src/` согласно требованиям проекта.

## Структура проекта

```
Decimal_For_School21/
├── README.md                   # Основной README проекта
├── Makefile                    # Главный Makefile (делегирует в src/build/)
├── PROJECT_STRUCTURE.md        # Этот файл
└── src/                        # Вся разработка внутри src/
    ├── s21_decimal.h           # Заголовочный файл библиотеки
    ├── s21_helpers.c           # Вспомогательные функции
    ├── s21_is_less.c           # Функции сравнения
    ├── s21_is_greater.c
    ├── s21_is_less_or_equal.c
    ├── s21_is_greater_or_equal.c
    ├── s21_from_int_to_decimal.c  # Функции конвертации
    ├── s21_from_decimal_to_int.c
    ├── tests/                  # Тесты
    │   ├── test_comparison.c   # Unit-тесты с Check
    │   └── test_simple.c       # Простые тесты
    ├── docs/                   # Документация
    │   ├── LEVEL4_README.md    # Документация функций
    │   └── MAKEFILE_USAGE.md   # Руководство по Makefile
    ├── build/                  # Сборка
    │   └── Makefile            # Makefile для сборки
    ├── tmp/                    # Временные файлы (автоматически создается)
    │   ├── *.o                 # Объектные файлы
    │   ├── *.gcno              # Gcov файлы
    │   ├── *.gcda
    │   ├── *.gcov
    │   ├── coverage/           # Отчеты покрытия
    │   └── test_*              # Исполняемые файлы тестов
    └── README.md               # README для src/
```

## Быстрый старт

### Из корня проекта:
```bash
# Сборка и тестирование
make all

# Только тестирование с очисткой
make test_clean

# Тестирование с Check библиотекой
make check_clean

# Генерация отчета покрытия
make gcov_report

# Показать справку
make help
```

### Из директории src/build:
```bash
cd src/build

# Сборка библиотеки
make s21_decimal.a

# Запуск тестов
make test_clean
make check_clean

# Генерация отчета покрытия
make gcov_report
```

## Реализованные функции (Уровень 4)

### Функции сравнения
- `s21_is_less` - сравнение "меньше" (<)
- `s21_is_greater` - сравнение "больше" (>)
- `s21_is_less_or_equal` - сравнение "меньше или равно" (<=)
- `s21_is_greater_or_equal` - сравнение "больше или равно" (>=)

### Функции конвертации
- `s21_from_int_to_decimal` - преобразование из int в decimal
- `s21_from_decimal_to_int` - преобразование из decimal в int

## Особенности структуры

### ✅ Изоляция разработки
- **Вся разработка в src/**: Исходный код, тесты, документация и сборка находятся внутри `src/`
- **Временные файлы в tmp/**: Все объектные файлы, gcov файлы и исполняемые файлы создаются в `src/tmp/`
- **Автоматическая очистка**: Временные файлы автоматически удаляются после тестирования

### ✅ Организация по типам
- **Исходный код**: `.c` и `.h` файлы в корне `src/`
- **Тесты**: В `src/tests/`
- **Документация**: В `src/docs/`
- **Сборка**: В `src/build/`
- **Временные файлы**: В `src/tmp/`

### ✅ Соответствие требованиям
- **C11 стандарт** с GCC компилятором
- **POSIX.1-2017** стандарт
- **Google Style** для C++
- **Check библиотека** для тестирования
- **Gcov** для анализа покрытия кода
- **Статическая библиотека** s21_decimal.a
